# Raph Tech Smart Task Manager

A simple task manager web app built with HTML and CSS 

## Features
- Add and manage tasks in a clean table layout
- Update task status with dropdown menus
- Responsive, easy-to-read design

## How to use
1. Download or clone this repository
2. Open `to do app/index.html` in your browser

## Built with
- HTML
- CSS
- JavaScript
